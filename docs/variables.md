## omerfsen.stratum.stratum

### Entry point `prepare`

Host prerequisites, firewalld and the verified Stratum binary.

| Variable | Type | Default | Description |
|---|---|---|---|
| `stratum_version` | str | `v1.37.1-stratum.0` | Stratum release tag. Supported out of the box are the keys of `stratum_releases`. |
| `stratum_releases` | dict |  | Known releases and the sha256 of their binary per architecture (`amd64`, `arm64`). |
| `stratum_sha256` | dict |  | sha256 per architecture for `stratum_version`, from the release's sha256sums.txt. Default the entry in `stratum_releases`. Set it for a release not in that table. |
| `stratum_binary_source` | str | `controller` | `controller` downloads once on the controller and pushes to the nodes, which need no internet access. `node` downloads on each node. |
| `stratum_release_url` | str | `https://github.com/ctrliq/stratum/releases/download` | Base URL of the releases. Point it at a mirror if needed. |
| `stratum_binary_local_path` | path | `""` | Air-gapped installs. An already downloaded binary on the controller; its sha256 is still checked. |
| `stratum_controller_cache_dir` | path |  | Download cache on the controller. Default `~/.cache/stratum/<version>`. |
| `stratum_verify_signature` | bool | `False` | Verify the release's keyless cosign signature on the controller (needs cosign). |
| `stratum_signature_identity` | str |  | Expected certificate identity. Default the upstream release workflow at the tag. |
| `stratum_signature_issuer` | str | `https://token.actions.githubusercontent.com` | Expected OIDC issuer of the signing certificate. |
| `stratum_bin_path` | path | `/usr/local/bin/stratum` | Install path on the nodes. |
| `stratum_allow_binary_replace` | bool | `False` | Replace the binary on a node that is already in a cluster. Off, a different version on such a node fails the run; upgrade clusters with `stratum upgrade`. |
| `stratum_require_selinux_enforcing` | bool | `True` | Fail unless SELinux is enforcing. |
| `stratum_firewalld` | raw | `auto` | `auto` configures firewalld only where it already runs. `true` installs and enables it. `false` never touches it. |
| `stratum_firewalld_zone` | str | `stratum` | firewalld zone that holds the node subnet and the cluster ports. |
| `stratum_node_cidr` | str | `""` | Node subnet bound to the zone. Required when firewalld is managed. |
| `stratum_dashboard_port` | int | `30443` | Dashboard NodePort opened in firewalld; 0 keeps it closed. |
| `stratum_pod_cidr` | str | `10.245.0.0/16` | Pod range, trusted in firewalld. Must match the cluster's. |

### Entry point `node`

Bootstrap the first control plane, join the others and the workers.

| Variable | Type | Default | Description |
|---|---|---|---|
| `stratum_control_plane_group` | str | `stratum_control_plane` | Inventory group of the control planes (an odd number). Its first host bootstraps. |
| `stratum_worker_group` | str | `stratum_workers` | Inventory group of the workers. |
| `stratum_node_ip` | str |  | Address Kubernetes uses for this node. Default the default-route IPv4. |
| `stratum_vip` | str | `""` | Control-plane VIP held by kube-vip. Required with more than one control plane. |
| `stratum_vip_interface` | str | `""` | Interface kube-vip announces the VIP on. Default the default-route interface. |
| `stratum_service_cidr` | str | `10.96.0.0/12` | Service range. Fixed after the cluster's first boot. |
| `stratum_cluster_domain` | str | `cluster.local` | Cluster DNS domain. Fixed after the cluster's first boot. |
| `stratum_selinux` | bool | `True` | Label Stratum's files for container-selinux. |
| `stratum_profile` | str | `""` | Node profile, e.g. `cis`. The CIS profile is part of Stratum PRO. |
| `stratum_extra_config` | dict | `{}` | Merged into `spec` of /etc/stratum/config.yaml on control planes. |
| `stratum_control_plane_taint` | bool | `False` | Taint the control planes NoSchedule so workloads run on workers only. |
| `stratum_join_token_ttl` | str |  | Lifetime of each join token; revoked earlier, once the node is Ready. Default `stratum_up_timeout` plus 15 minutes (45m), longer than every wait of one join. |
| `stratum_up_timeout` | int | `1800` | Seconds allowed for one `stratum up`. |
| `stratum_fetch_kubeconfig` | bool | `True` | Copy an admin kubeconfig to the controller. |
| `stratum_cluster_name` | str | `stratum` | Name of the cluster, user and context in the exported and merged kubeconfig. Use a different one per cluster. |
| `stratum_kubeconfig_dest` | path |  | Standalone kubeconfig on the controller. Default `~/.kube/<cluster name>.yaml`; empty writes none. |
| `stratum_kubeconfig_merge` | bool | `False` | Also merge it into `stratum_kubeconfig_merge_path`. Off by default, so the main kubeconfig is never touched unless asked. Cluster, user and context entries named `stratum_cluster_name` are replaced, all others kept; a backup is taken before each change. |
| `stratum_kubeconfig_merge_path` | path | `~/.kube/config` | The main kubeconfig to merge into. |
| `stratum_kubeconfig_set_current` | bool | `True` | When merging, make the merged context the current one. |
